# US-01: Consultar dados públicos de uma empresa a partir do CNPJ

---

## 1. Descrição

**Como** usuário

**Quero** fazer login com e-mail e senha

**Para** acessar o sistema

## 2. Critérios de Aceitação

- **Cenário 1 – Login bem-sucedido**

```gherkin
  Given estou na tela de login
  When preencho o campo "E-mail" com um e-mail válido
    And preencho o campo "Senha" com a senha correta
    And clico no botão "Entrar"
  Then sou redirecionado para a biblioteca de teses
```

- **Cenário 2 – Campos obrigatórios vazios**

```gherkin
  Given estou na tela de login
  When clico no botão "Entrar" sem preencher os campos obrigatórios
  Then os campos vazios são destacados em vermelho
    And vejo as mensagens "E-mail é obrigatório" e/ou "Senha é obrigatória"
```

- **Cenário 3 – E-mail com formato inválido**

```gherkin
  Given estou na tela de login
  When digito um texto no campo "E-mail" que não tem formato de e-mail
  Then vejo a mensagem "E-mail inválido"
    And o campo "E-mail" é destacado em vermelho
```


- **Cenário 4 – Login mal-sucedido**

```gherkin
  Given estou na tela de login
  When preencho o campo "E-mail" com um e-mail válido
    And preencho o campo "Senha" com a senha incorreta
    And clico no botão "Entrar"
  Then o sistema não permite o login
```

## 3. Dependências

- Nenhuma
