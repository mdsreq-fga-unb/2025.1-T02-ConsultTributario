# US-19: Visualizar categorias de teses tributária cadastradas

---

## 1. Descrição

**Como** administrador

**Quero** visualizar uma lista com todas as categorias de teses tributárias cadastradas no sistema

**Para** entender como as teses estão organizadas e facilitar a navegação e o filtro por temas

## 2. Critérios de Aceitação

- **Background**

```gherkin
  Given estou logado como Administrador
    And acesso a página “Categorias”
```

- **Cenário 1 – Listagem de categorias**

```gherkin
  Then vejo uma tabela com todos os tipos de impostos cadastrados
    And cada linha exibe: nome do impostos e data da última atualização
```

- **Cenário 2 – Ordenação por nome**

```gherkin
  When clico no cabeçalho “Nome”
  Then a tabela é ordenada alfabeticamente (A → Z)
  When clico novamente
  Then a ordenação é invertida (Z → A)
```

- **Cenário 3 – Ordenação por data**

```gherkin
  When clico no cabeçalho “Atualizado em”
  Then a tabela é ordenada da data mais recente para a mais antiga
  When clico novamente
  Then a ordenação é invertida (mais antiga → mais recente)
```

- **Cenário 4 – Ações disponíveis**

```gherkin
  Then em cada linha vejo o botão de edição
    And ao clicar sou direcionado para o modal de edição do imposto (US-17)
  Then vejo um botão "Adicionar Imposto"
    And ao clicar sou direcionado para o modal de criação do tipo de imposto (US-06)
```

## 3. Dependências

- Endpoint: `GET /tax-types` retornando nome e `updatedAt`
